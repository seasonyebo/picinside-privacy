서비스와 보호 범위

PicInside는 사진·영상 보관과 사진 메모, 모음·즐겨찾기 관리, 선택적 보안 앨범과 백업 기능을 제공합니다. 사용자가 선택한 여러 외부 폴더에서 내용이 완전히 같은 파일을 찾아, 확인 후 정리하는 기능도 제공합니다.

외부 폴더 검사는 갤러리에 모든 문서 형식을 가져오는 기능과는 다릅니다. 일반 Main/Sub 원본 보관과 보안 앨범의 추가 암호화도 다른 보호 방식입니다. 모든 자료의 완전한 은닉, 모든 파일 형식 지원이나 어떤 상황에서도 복구됨을 보장하지 않습니다. 사용할 권한이 있는 자료만 처리하세요.

구독과 기존 자료

PicInside Pro는 App Store의 월간·연간 자동 갱신 구독입니다. 실제 가격·기간·갱신 조건은 Apple 구매 화면에서 확인하세요. 앱을 삭제해도 구독은 자동 취소되지 않습니다.

구독 변경·취소는 iPhone 설정 → 사용자 이름 → 구독 → PicInside에서 할 수 있습니다. 구입한 이용 권한이 보이지 않으면 앱 구독 화면의 ‘구독 복원’을 이용하세요. 환불 요청은 Apple의 환불 안내를 따르며, 처리 결과는 해당 절차와 적용 법률에 따릅니다. 이는 운영자의 법률상 의무나 소비자 권리를 없애지 않습니다.

구독 만료는 기존 자료의 열람·재생·검색·정리·내보내기·삭제·복구·수동 백업과 복원 권리를 없애지 않습니다. Basic의 10개 한도는 새 외부 사진·영상 유입에 적용하며, Pro 전용 작업의 실행 여부와 기존 자료 권리는 별개입니다.

Pro 전용 기능은 새 모음·모음 그룹 만들기, 상세 용량 관리와 재생성 가능한 캐시 정리, 인스페이스의 정확 중복 찾기, iCloud 자동 백업 실행입니다. 외부 폴더의 중복 파일 검사는 이 인스페이스 전용 기능과 구분됩니다.

여러 검사 폴더의 등록·관리, 실제 중복 검사·재검사, 중복 사본 수와 크기 합계 요약은 무료입니다. 그룹별 상세 목록과 개별 파일명·위치, 이미지·PDF·영상 미리보기, 남길 사본 추천·선택 변경·선택한 파일 정리는 기존 PicInside Pro에 포함됩니다. 별도 상품·가격이나 무료 검사 횟수 제한은 없습니다. 검증된 구매·복원 후에는 유효한 기존 결과를 다시 검사하지 않고 열 수 있으며, 구매만으로 파일을 삭제하지 않습니다. 정리에는 별도 확인이 필요합니다. Pro로 이미 열어본 최근 상세 결과와 최근 정리 완료 내역은 만료 후에도 읽기 전용으로 유지되지만, 새 결과의 상세 보기나 새 정리 권한을 주지는 않습니다. 검사 취소·폴더 연결 해제·검사 기록 삭제·지원 이용은 무료입니다. 검사 기록을 지워도 등록 폴더와 원본 파일은 삭제하지 않습니다. 가져오기 중 동일 파일 경고는 기본 제공하며 Basic의 10개 한도를 외부 검사 파일 수에 적용하지 않습니다.

원본·삭제·백업

가져오기는 Photos·Files 입력 원본을 자동 삭제하지 않습니다. 외부 중복 정리는 선택한 파일을 실제 원래 위치에서 삭제하며 제공자에 따라 복구가 불가능할 수 있습니다. 여러 파일 정리는 일부만 성공할 수 있고 취소는 이미 완료된 삭제를 되돌리지 않습니다. 보존할 자료와 별도 백업을 확인한 뒤 삭제하세요. 기기 내 자료의 삭제·앱 삭제·구독 해지가 외부 백업을 자동 삭제하지는 않습니다.

암호와 복구 책임

복구 키는 삭제된 미디어를 대신하는 복사본이 아닙니다. 보안 암호 재설정은 해당 복구 수단을 미리 준비한 보안 폴더에 한합니다. 비상 백업은 생성 당시의 키가 필요하며 오래된 백업에 새 키가 자동 적용되지 않습니다. 복구 수단을 별도로 안전하게 보관하세요. Main과 Sub는 서로 다른 인증 경로와 키를 사용합니다. 관리자용 연결을 준비해도 기존 Sub 암호 로그인과 자료는 유지되며, 보안 폴더의 별도 보안 암호를 대신하지 않습니다.

이 약관과 Apple EULA
