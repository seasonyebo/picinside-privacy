운영 브랜드와 적용 범위

PicInside의 정식 사업자 상호는 스튜디오 JS (Studio JS), 공개 브랜드는 Studio JS입니다. 대표가 직접 운영하는 1인 사업자입니다. 이 방침은 앱의 정보 처리, 사용자가 선택하는 외부 서비스, 지원 문의와 공개 웹페이지를 구분해 설명합니다.

사진·영상과 기기 내 보호

일반 Main/Sub 인스페이스는 가져오기 과정에서 받은 원본 파일을 재압축하거나 재인코딩하지 않고 그대로 보관합니다. 가져올 수 있는 형식과 원본 종류는 iOS와 파일 제공자가 지원하는 범위에 따라 달라질 수 있습니다.

이 미디어 파일 자체에는 PicInside의 추가 암호화를 적용하지 않으며 iOS 파일 보호와 앱 잠금으로 보호합니다. 원본을 유지하므로 파일에 포함된 촬영·위치 정보도 남을 수 있습니다.

파일명·종류·크기·날짜·해상도·영상 길이·즐겨찾기 등 보관함 정보, 사진 메모·태그와 파생 썸네일은 기기 내에서 처리하며 해당 저장소의 인증 암호화로 보호합니다. 이를 PicInside 운영 서버에 전송하는 기능이나 분석·광고 SDK는 현재 앱에 없습니다.

보안 폴더와 복구

보안 폴더(보안 앨범)는 사진·영상을 재압축하거나 재인코딩하지 않고, 파일마다 다른 미디어 키로 추가 인증 암호화합니다. 완전히 복호화해 내보낸 파일은 입력 원본과 바이트 단위로 같습니다.

보안 암호를 잊었을 때 복구 키(Recovery Key)로 암호를 재설정할 수 있는 것은 해당 키로 복구를 미리 준비한 보안 폴더뿐입니다. 보안 암호와 유효한 복구 수단을 모두 잃으면 잠긴 자료를 복구할 수 없습니다. 복구 키는 삭제된 파일을 되살리는 백업이 아닙니다.

Main·Sub와 기존 자료 보호

Main과 Sub는 별도의 인증 경로와 키를 사용하는 분리된 공간입니다. 기존 Sub는 Main 관리자 인증 상태에서 Sub 암호를 한 번 확인해 관리 연결을 준비할 수 있으며, 새 Sub는 생성 과정에서 연결을 준비합니다. 연결 후 관리자 홈의 Sub 카드는 추가 암호 입력 없이 연결된 Sub를 엽니다.

이 연결은 Sub 키를 추가로 암호화해 여는 권한을 준비하는 것이며 두 공간의 키를 합치거나 일반 미디어 파일을 다시 암호화하는 동작이 아닙니다.

Sub 로그인은 관리자 권한을 부여하지 않습니다. 관리 연결 준비를 취소하거나 연결이 준비되지 않아도 기존 Sub 암호 로그인과 자료는 유지되며, 복원이나 키 변경 후에는 연결을 다시 준비해야 할 수 있습니다.

기존 Sub 보안 자료는 Main 관리자 설정의 보안 폴더 → 기존 서브 보안 자료에서 관리합니다. 보기·내보내기·백업·복원 등 기존 자료 이용에 새 결제가 필요하지 않습니다. 보안 암호가 설정된 보안 폴더는 관리자 로그인만으로 열 수 없으며, 해당 보안 암호 또는 미리 준비한 유효한 복구 수단이 필요합니다.

외부 폴더 검사와 캐시

외부 중복 검사는 사용자가 선택해 접근을 허용한 여러 폴더를 대상으로 합니다. 다시 검사할 때 사용할 파일 정보와 내용 비교용 데이터를 기기에 보관합니다.

보관 항목은 폴더 접근 북마크, 폴더 이름·위치 표시, 파일의 상대 경로·이름·크기·날짜·식별 정보·처음 발견한 순서와 내용 지문입니다. 지문은 파일 내용이 같은지 비교하는 데이터이며 파일 원본의 복사본은 아닙니다.

이 별도 검사 저장소는 독립된 파일 키로 인증 암호화하고 iOS 파일 보호를 적용하며 OS 백업에서 제외합니다. 보안 폴더의 보안 암호로 보호되는 저장소는 아닙니다. 앱을 닫을 때마다 삭제하거나 일정 기간 후 자동 삭제하지 않습니다.

검사에 사용한 전체 내용의 SHA-256, 최신 검사 결과, 마지막으로 Pro에서 연 상세 결과와 최근 정리 내역도 이 암호화된 저장소에 보관합니다. 같은 결과를 다시 열 때 선택을 복원할 수 있도록, 남길 파일 변경과 정리 선택 변경 정보만 함께 저장합니다. 결과나 파일 구성이 달라지면 이전 선택을 새 결과에 그대로 적용하지 않습니다.

관리자 홈 → 중복 파일 검사·정리 → 중복 파일 찾기에서 해당 폴더의 − 버튼(‘검사 목록에서 제거’)를 선택하면 등록과 관련 검사 정보를 제거하고 원본은 남깁니다. 이는 해당 등록을 제거하는 동작이며 파일 제공자나 OS의 모든 권한·캐시를 철회하거나 삭제한다는 뜻은 아닙니다.

‘검사 기록 삭제’는 검사 캐시·저장 결과·최근 정리 내역·저장된 선택 정보를 지우고, 등록 폴더와 실제 파일은 남깁니다. 폴더 연결을 해제하면 해당 등록·캐시와 최신 결과·선택 정보가 무효화되고, 그 폴더를 포함한 과거 열람 결과·정리 내역도 제거됩니다.

미리보기·삭제와 파일 제공자

중복은 파일 이름이나 일부 샘플만이 아니라 전체 내용의 비교용 지문으로 확정합니다. 삭제는 명시적 선택·확인 후 남길 파일과 삭제할 파일을 다시 검증해 진행합니다.

남길 파일과 정리 대상의 선택을 저장하는 것은 삭제 승인을 저장하는 것이 아닙니다. 백그라운드 전환이나 인증 경계를 지나면 기존 정리 확인은 다시 받아야 하며, 선택을 복원하거나 파일 준비가 끝났다는 이유로 자동 삭제하지 않습니다.

외부 삭제는 PicInside 내부 휴지통으로 옮기는 동작이 아닙니다. 제공자에 따라 영구 삭제될 수 있고 복구 기간을 보장하지 않습니다. 취소해도 이미 삭제된 항목이 되돌아오지는 않습니다.

미리보기는 시스템 Quick Look과 선택한 파일 제공자를 이용할 수 있습니다. 온라인 파일은 다운로드가 필요할 수 있습니다. 제공자는 요청한 파일·경로 및 접속 관련 정보를 처리할 수 있고, 네트워크 처리·시스템 캐시에는 해당 서비스 정책이 적용됩니다. PicInside가 모든 시스템 캐시의 즉시 삭제를 보장하지는 않습니다.

외부 결과 목록에서 PicInside가 만드는 썸네일 캐시는 개수·메모리 사용량을 제한해 메모리에만 유지하며 별도 디스크 사본으로 저장하지 않습니다. 시스템이나 파일 제공자가 관리하는 캐시는 이와 별개입니다.

Files·iCloud Drive·CloudKit 백업

수동 비상 백업은 별도로 암호화해 사용자가 선택한 Files, iCloud Drive 등의 위치에 저장합니다. 복원에는 생성 당시의 복구 키가 필요할 수 있으며 새 키가 과거 백업을 자동 변경하지 않습니다.

Pro에서 iCloud 자동 백업을 켜면 암호화된 미디어 조각·상세 보관함 정보·복구 자료를 사용자의 비공개 CloudKit 데이터베이스에 저장합니다. 객체 식별자, 조각 순서·크기, 백업 시각·항목 수·합계 크기와 기기 구분 식별자 같은 운영 정보까지 모두 PicInside 암호문인 것은 아닙니다.

Main 관리자 인증 후에는 구독 상태와 관계없이 자동 백업을 끌 수 있습니다. 다시 켜기에는 기존 Pro 권한과 복구 준비 조건이 적용됩니다. 끄기 설정이 저장되면 앱을 다시 열거나 재구독해도 자동으로 켜지지 않습니다.

기기 내 파일 삭제, 자동 백업 끄기나 구독 만료가 외부 백업 삭제를 뜻하지 않습니다. 이전 스냅샷의 일부 정보만 정리하며 복구 안전성을 위해 사용되지 않는 암호화 조각이 남을 수 있습니다.

수동 백업 파일은 저장한 Files 위치에서 해당 파일을 선택해 관리합니다. 공유하거나 복사한 백업도 각각 남습니다. 앱에는 비공개 CloudKit 백업 전체와 잔존 조각을 삭제하는 메뉴가 없습니다. 복구에 필요한 조각을 임의로 나누어 삭제하지 마세요. 운영자는 사용자의 비공개 백업을 지원 이메일로 대신 삭제할 수 없습니다. Apple 및 선택한 저장 서비스의 관리·보존 조건도 적용됩니다.

Apple 결제와 자료 이용 권리

구매와 결제는 Apple이 처리합니다. 앱은 StoreKit의 검증된 거래·갱신·이용 상태를 확인하고, 로컬 이용 상태 기록에는 기록 형식 버전과 상태 종류·검증 시각·유효 기한을 보호해 저장합니다. 결제 카드 정보나 Apple 계정 정보를 이 로컬 기록에 저장하지 않습니다.

구독이 끝나도 PicInside 보관함에 이미 저장한 자료의 열람·재생·검색·정리·내보내기·삭제·복원과 수동 백업 권리는 유지됩니다. Basic의 10개 한도는 새 외부 사진·영상 유입에 적용되는 제한이며 기존 자료를 자동 삭제하는 기준이 아닙니다.

보존·삭제와 사용자 선택

갤러리에서 삭제한 항목은 해당 공간의 휴지통으로 이동합니다. 휴지통 이동 시각부터 14일 안에 복원하거나 그 전에 영구 삭제할 수 있습니다. 만료 항목은 해당 공간을 다시 읽을 때의 정리 과정에서 삭제하며, 정확한 만료 시각에 백그라운드에서 삭제됨을 보장하지 않습니다. 보안 앨범의 휴지통은 일반 휴지통과 분리되고, 복원·영구 삭제·만료 정리에는 해당 앨범의 유효한 접근 권한이 필요합니다.

Photos·Files의 입력 원본은 자동 삭제하지 않습니다. 앱 삭제 시 로컬 자료가 사라질 수 있지만 Keychain 인증 자료나 외부 백업까지 모두 삭제된다는 보장은 없습니다. 현재 앱에는 모든 PicInside Keychain 항목을 삭제하는 메뉴가 없습니다. Face ID 끄기는 생체인증용 키 사본만 제거하며 로그인·복구 정보 전체 삭제가 아닙니다.

일반 문의 정보는 처리 완료 후 90일 이내에 삭제합니다. 90일은 보관 상한이며 필요가 없어진 정보는 그 전이라도 지체 없이 삭제합니다. 실제 적용 법령이 보존을 요구하는 경우 대상 정보만 법정 기간 동안 별도로 보관하고 기간 종료 후 삭제합니다. 일반 사용 문의와 소비자 불만·분쟁 처리 기록은 구분합니다.

운영자가 취급하는 PicInside Pro의 계약·청약철회 기록과 대금결제·서비스 공급 기록은 대한민국 전자상거래법 제6조 및 같은 법 시행령 제6조에 따라 각각 5년, 소비자 불만·분쟁 처리 기록은 3년 보존합니다. 대상은 해당 거래나 사건에 필요한 식별·연락 정보, 상품·일자·금액, 요청·처리 결과 등 실제 취급하는 최소 정보로 한정합니다. 모든 일반 문의나 무관한 첨부파일을 이 기간 동안 보관한다는 뜻은 아닙니다. 해당 기록은 일반 문의와 분리해 법정 보존 목적으로만 관리하고, 기간이 끝나면 삭제합니다.

대표는 문의 처리 완료일을 기록해 정기적으로 점검하고, 관리 중인 삭제 대상 메일과 사본이 기한 내 삭제됐는지 확인합니다. 대상 메일이 Gmail 휴지통에 남지 않도록 확인하며 관리 기록에도 본문·첨부파일을 불필요하게 복제하거나 무기한 보관하지 않습니다. Gmail 자동삭제가 설정됐다는 뜻은 아닙니다.
