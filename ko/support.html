자료가 보이지 않거나 잠겼다면

자료가 보이지 않거나 잠겼다면 앱 삭제·Keychain 초기화를 하지 마세요. 원본과 백업을 보존하고 현재 화면·오류를 확인하세요. 복구 키는 남아 있는 잠금 자료를 여는 수단이며 삭제된 미디어의 백업은 아닙니다.

앱 안의 자료: 해당 인스페이스의 갤러리에서 항목을 삭제하면 휴지통으로 이동합니다. 하단 ‘휴지통’에서 항목을 선택해 ‘복구’ 또는 ‘영구 삭제’를 선택합니다. 14일 기한과 보안 앨범 접근 조건은 개인정보처리방침의 보존·삭제 항목을 확인하세요.

보안 자료: 관리자 홈 → 앱 설정 열기 → 보안 폴더 → 보안 폴더 열기에서 필요한 인증을 거친 뒤 내부 휴지통을 사용합니다. 과거 Sub 보안 자료는 같은 설정의 ‘기존 서브 보안 자료’에서 기존 보안 암호·복구 조건으로 접근합니다.

수동 백업: 저장했던 Files 위치에서 백업 파일을 선택해 관리하세요. 삭제 전에 남길 백업과 생성 당시의 복구 키를 확인하고 복사·공유한 파일도 별도로 관리하세요. 제공자의 휴지통·영구 삭제와 복구 조건이 적용됩니다.

iCloud 자동 백업: Main 관리자 인증 후 앱 설정 → 백업 및 복원에서 구독 상태와 관계없이 끌 수 있습니다. 구독 확인 중이나 오프라인이어도 끄기가 가능하며, 다시 켜기에는 기존 Pro 권한과 복구 준비 조건이 적용됩니다. 끄기 설정이 저장되면 앱을 다시 열거나 재구독해도 자동으로 켜지지 않습니다.

끄기 설정 저장에 실패하면 완료로 표시하지 않습니다. 확인된 저장 상태 또는 상태 확인 필요 안내를 보고 ‘끄기 다시 시도’를 선택하세요. 이번 앱 실행 중 새 자동 백업은 대기하지만, 저장되지 않은 끄기 설정이 재실행 후에도 유지된다고 보장할 수는 없습니다. 이미 시작된 백업은 안전하게 마무리될 수 있습니다.

자동 백업을 꺼도 이미 저장된 백업은 삭제되지 않습니다. 현재 앱에는 CloudKit 백업 전체·잔존 조각 삭제 메뉴가 없습니다. 지원 문의로 운영자가 대신 삭제하거나 조각별 삭제를 안내할 수 없습니다.

Keychain: 관리자 홈의 Face ID → Face ID 끄기는 생체인증용 키 사본만 제거합니다. 로그인·복구 키 전체 삭제 메뉴는 없으며 자료가 잠긴 상태를 해결하려고 Keychain을 초기화하지 마세요.

외부 폴더와 삭제

관리자 홈 → 중복 파일 검사·정리 → 중복 파일 찾기에서 선택한 폴더의 권한과 파일 제공자의 연결 상태를 확인하세요. 온라인 파일은 다운로드가 필요할 수 있습니다.

해당 폴더의 − 버튼(‘검사 목록에서 제거’)는 등록과 관련 검사 정보를 제거하고 원본은 삭제하지 않습니다. 다른 앱이나 제공자의 접근 권한·시스템 캐시까지 취소하는 동작은 아닙니다.

‘검사 기록 삭제’는 검사 캐시·저장 결과·최근 정리 내역·저장된 선택 정보를 지우고, 등록 폴더와 실제 파일은 남깁니다. 폴더 연결을 해제하면 해당 등록·캐시와 최신 결과·선택 정보가 무효화되고, 그 폴더를 포함한 과거 열람 결과·정리 내역도 제거됩니다.

외부 파일 정리는 PicInside 내부 휴지통으로 옮기는 기능이 아닙니다. 복구 가능 여부와 기간은 파일을 보관한 서비스에 따라 다릅니다. 해당 서비스의 삭제 항목 관리·지원 절차를 확인하세요.

정리 전에는 남길 파일과 정리 대상 모두의 준비 상태를 확인합니다. 다운로드 필요·상태 미확인·접근 오류로 중단되면 해당 안내에 따라 Files 또는 파일 제공 앱에서 상태를 확인한 뒤 다시 확인해 주세요. 파일 준비만으로 자동 정리하지 않으며, 준비 후에도 기존 파일·내용 검증과 최종 확인이 필요합니다.

구독과 백업

구독 변경·취소: iPhone 설정 → 사용자 이름 → 구독 → PicInside. 구입한 이용 권한이 나타나지 않으면 PicInside 구독 화면의 ‘구독 복원’을 이용하세요. 환불은 아래 Apple 공식 안내에서 요청할 수 있습니다.

구독 만료 후에도 기존 자료와 수동 백업·복원 권리는 유지됩니다. 자동 백업 실행 중단은 이미 저장된 클라우드 백업의 삭제가 아닙니다. 앱 삭제나 초기화 전에 복원 가능한 외부 백업을 확인하세요.

여러 검사 폴더의 등록·관리, 실제 중복 검사·재검사, 중복 사본 수와 크기 합계 요약은 무료입니다. 그룹별 상세 목록과 개별 파일명·위치, 이미지·PDF·영상 미리보기, 남길 사본 추천·선택 변경·선택한 파일 정리는 기존 PicInside Pro에 포함됩니다. 별도 상품·가격이나 무료 검사 횟수 제한은 없습니다. 검증된 구매·복원 후에는 유효한 기존 결과를 다시 검사하지 않고 열 수 있으며, 구매만으로 파일을 삭제하지 않습니다. 정리에는 별도 확인이 필요합니다. Pro로 이미 열어본 최근 상세 결과와 최근 정리 완료 내역은 만료 후에도 읽기 전용으로 유지되지만, 새 결과의 상세 보기나 새 정리 권한을 주지는 않습니다. 검사 취소·폴더 연결 해제·검사 기록 삭제·지원 이용은 무료입니다. 검사 기록을 지워도 등록 폴더와 원본 파일은 삭제하지 않습니다. 가져오기 중 동일 파일 경고는 기본 제공하며 Basic의 10개 한도를 외부 검사 파일 수에 적용하지 않습니다.
