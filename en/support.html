Preparing a problem report

App version, iOS version, device model, approximate time and steps to reproduce can help. Hide personal information in an error screenshot and share it only when needed. Do not send real filenames, folder paths, photos, videos, login patterns, passwords, security passwords, Recovery Keys or cryptographic keys. Do not send card details or authentication information for billing questions either.

If content is missing or locked

If content is missing or locked, do not delete the app or reset Keychain. Preserve originals and backups and note the screen or error. A Recovery Key opens remaining protected data; it is not a backup of deleted media.

App content: delete an item in that InSpace's Gallery to move it to Trash. Open the bottom Trash tab, select the item, then choose “Recovery” or “Delete Permanently”. See Privacy Policy retention for the 14-day deadline and Secure Album access conditions.

Secure content: administrator Home → Open App Settings → Secure Folder → Open Secure Folder, then authenticate as required and use its Trash. Older Sub secure content is under Legacy Sub Secure Data in the same settings, with the existing security password and recovery conditions.

Manual backups: select the backup in its saved Files location. Before deletion, check which backup you will keep and its creation-time Recovery Key. Manage copied or shared backups separately. The provider's Trash, permanent-deletion and recovery rules apply.

iCloud Automatic Backup: after Main administrator authentication, open App Settings → Backup and Restore to turn it off regardless of subscription status. You can turn it off while the status is being checked or you are offline. Turning it back on still requires verified Pro access and recovery setup. Once Off is saved, reopening the app or resubscribing does not turn it on automatically.

If saving Off fails, it is not shown as complete. Check the verified saved setting or the status-verification notice, then choose Retry Turning Off. New automatic backups are paused for this app session, but an unsaved Off setting is not guaranteed to persist after reopening the app. A backup already started may finish safely.

Turning off automatic backup does not delete stored backups. The app currently has no menu to delete all CloudKit backups and residual chunks. Support cannot delete them for you or guide piecemeal chunk deletion.

Keychain: administrator Home → Face ID → Turn Off Face ID removes only the biometric key copy. There is no all-login/recovery-key deletion menu. Do not reset Keychain to troubleshoot locked content.

External folders and deletion

In administrator Home → Find & Clean Up Duplicate Files → Find Duplicate Files, check permission for the selected folder and the provider's connection. Online files may need downloading.

The − button (Remove from Scan List) removes that folder's registration and related scan information, not the source files. It does not revoke other apps' or providers' permissions or clear all system caches.

Clear Scan History removes the scan cache, saved results, latest cleanup record and saved selections, while keeping registered folders and actual files. Disconnecting a folder invalidates its registration and cache, the latest result and saved selections; it also removes previously viewed results and cleanup records that include that folder.

External cleanup does not move files to PicInside's internal Trash. Whether you can restore a deleted file, and for how long, depends on the service storing it. Check that service's deleted-item controls or support.

Before cleanup, PicInside checks the readiness of both the copy to keep and the copies selected for removal. If it stops because a download is needed, readiness is unknown or access fails, follow the notice and check the file in Files or its provider app before confirming again. Making files ready does not start cleanup; file and content validation and final confirmation still apply.

Subscriptions and backups

Manage or cancel a subscription in iPhone Settings → your name → Subscriptions → PicInside. If purchased access is missing, use Restore Purchases on PicInside's subscription screen. The official Apple guidance below explains refund requests.

Expiration does not remove existing-data rights or manual backup and restore. Stopping automatic backup does not delete cloud backups already stored. Check that you have a usable external backup before deleting or resetting the app.

Registering and managing folders, running duplicate scans and rescans, and viewing aggregate duplicate-copy counts and sizes are free. The existing PicInside Pro subscription includes group-by-group details, individual filenames and locations, image/PDF/video previews, keeper recommendations, selection changes and cleanup of selected files. There is no separate product or price and no free-scan count limit. After a verified purchase or restoration, a valid existing result can open without another scan. Purchasing never deletes files; cleanup requires separate confirmation. The most recently Pro-opened detailed result and latest cleanup outcomes remain available read-only after expiration, without unlocking details for a new result or authorizing new cleanup. Cancelling scans, disconnecting folders, clearing scan history and contacting support remain free. Clearing history does not delete registered folders or source files. Import duplicate warnings are included, and Basic's 10-item import limit does not apply to external scan files.
