問題を説明する前に

アプリのバージョン、iOSのバージョン、機種、発生時刻、再現手順を整理すると役立ちます。エラー画面の個人情報を隠し、必要な場合だけ共有してください。実際のファイル名・フォルダパス・写真・ビデオ・ログインパターン・パスワード・セキュリティパスワード・復旧キー・暗号鍵は送らないでください。決済の問い合わせでもカード情報や認証情報は送らないでください。

データが見つからない・開けないとき

データが見つからない・開けない場合はアプリ削除やKeychain初期化をせず、元ファイル・バックアップと現在の画面やエラーを確認してください。復旧キーは残っている保護データを開くためのもので、削除したメディアのバックアップではありません。

アプリ内データ：そのInSpaceのギャラリーで削除するとゴミ箱へ移動します。下部の「ゴミ箱」で項目を選び「復旧」または「完全に削除」を選択します。14日の期限とセキュアアルバムへのアクセス条件はプライバシーポリシーの保管・削除をご確認ください。

セキュアデータ：管理者ホーム → アプリ設定を開く → セキュアフォルダ → セキュアフォルダを開くで必要な認証を行い、内部のゴミ箱を使用します。旧Subのセキュアデータは同じ設定内の「既存のサブのセキュアデータ」から、従来のパスワード・復旧条件でアクセスします。

手動バックアップ：Filesの保存先で対象を選びます。削除前に残すバックアップと作成時の復旧キーを確認し、コピー・共有したファイルも別途管理してください。提供元のゴミ箱・完全削除・復元の条件が適用されます。

iCloud自動バックアップ：Main管理者認証後、アプリ設定 → バックアップと復元からサブスクリプション状態に関係なくオフにできます。状態確認中やオフラインでもオフにできます。再びオンにするには、引き続き有効なPro利用権限と復旧の準備が必要です。オフ設定が保存されると、アプリを開き直したり再購読したりしても自動ではオンになりません。

オフ設定の保存に失敗した場合は、完了として表示しません。確認できた保存状態、または状態の確認が必要という案内を確認し、「オフ設定を再試行」を選んでください。今回の起動中は新しい自動バックアップを待機しますが、保存されていないオフ設定が再起動後も維持されるとは限りません。開始済みのバックアップは安全に完了する場合があります。

自動バックアップをオフにしても既存のバックアップは削除されません。現在、CloudKitバックアップ全体と残存断片を削除するメニューはありません。サポートが代わりに削除したり、断片ごとの削除を案内したりすることはできません。

Keychain：管理者ホームのFace ID → Face IDをオフは、生体認証用の鍵のコピーだけを削除します。全ログイン・復旧鍵を削除するメニューはなく、開けない問題の解決のためにKeychainを初期化しないでください。

外部フォルダと削除

管理者ホーム → 重複ファイルの検索・整理 → 重複ファイルを探すで選択したフォルダの権限と提供元の接続状態を確認してください。オンラインファイルはダウンロードが必要な場合があります。

−ボタン（「検査リストから削除」）はその登録と関連する検査情報を削除し、元ファイルは削除しません。他のアプリや提供元の権限取り消し、システムキャッシュの全削除は行いません。

「検査履歴を削除」は検査キャッシュ・保存結果・直近の整理記録・保存した選択を削除し、登録フォルダと実際のファイルは残します。フォルダの接続を解除すると、その登録・キャッシュ、最新の結果・保存した選択は無効になり、そのフォルダを含む過去の閲覧結果・整理記録も削除されます。

外部ファイルの整理はPicInside内部のゴミ箱への移動ではありません。復元できるかどうかや復元可能な期間は保存先のサービスによって異なります。そのサービスの削除済み項目の管理やサポートをご確認ください。

整理前に、残すファイルと整理対象の両方の準備状態を確認します。ダウンロードが必要・状態が不明・アクセスエラーで中断した場合は、案内に従ってFilesまたはファイル提供元のアプリで状態を確認してから、再度確認してください。準備だけで自動整理は行わず、準備後もファイル・内容の検証と最終確認が必要です。

購読とバックアップ

変更・解約はiPhoneの設定 → 自分の名前 → サブスクリプション → PicInsideから行います。購入済みの利用資格が表示されない場合はPicInsideの購読画面で「購入を復元」を使用してください。返金申請は下記のApple公式案内をご確認ください。

購読終了後も既存データと手動バックアップ・復元を利用できます。自動バックアップの停止は保存済みクラウドバックアップの削除ではありません。アプリの削除・初期化前に復元可能な外部バックアップを確認してください。

検査フォルダの登録・管理、実際の重複検査・再検査、重複コピー数と合計サイズの確認は無料です。グループ別の詳細一覧と個別ファイル名・場所、画像・PDF・ビデオのプレビュー、残すコピーの提案・選択変更・選択ファイルの整理は、既存のPicInside Proに含まれます。別の商品・料金や無料検査の回数制限はありません。購入・購入の復元が確認されると、有効な既存の結果を再検査せずに開けます。購入だけでファイルを削除することはなく、整理には別途確認が必要です。最後にProで開いた詳細結果と直近の整理結果は購読終了後も読み取り専用で確認できますが、新しい結果の詳細表示や新たな整理の権限には引き継がれません。検査の中止、フォルダの接続解除、検査履歴の削除、サポートの利用は無料です。履歴を削除しても登録フォルダや元ファイルは削除されません。読み込み時の同一ファイルの警告は基本機能で、Basicの10件上限は外部検査のファイル数には適用されません。
